# Lumo（记账）

> 一个**纯本地、不联网、完全免费**的 Android 记账 App。
> 所有数据只存在你自己的手机上，没有账号、没有云同步、没有广告、没有网络权限。

- 包名：`com.qingjizhang.app`
- 当前版本：**v2.9.0**（versionCode 50，数据库 v17）
- 最低支持：Android 8.0（API 26）及以上
- License：**AGPL-3.0**（GNU Affero General Public License v3.0）

---

## 一、这个 App 是什么

Lumo 是一个把「记一笔」做到最快的本地记账工具：打开即记、记完即走，不打扰。
它不做理财推荐、不做社交、不做云备份，只做一件事——**把你自己的账，存在你自己的手机里**。

设计上有几条不做妥协的原则：

1. **绝不联网**：`AndroidManifest.xml` 里没有 `INTERNET` 权限，代码中也不存在任何网络请求（没有 OkHttp / Retrofit / 任何 HTTP 客户端依赖）。数据在物理上不可能被上传。
2. **绝不要求登录**：没有账号体系，没有服务端。
3. **绝不上传任何数据**：备份、导出、导入全部走本机文件系统，由你自己选择保存位置。
4. **免费且长期免费**：不设内购、不设会员、不投放广告。

## 二、功能特性

### 记一笔（核心）
- 自绘记账键盘（数字 / 计算器两种模式），支持「再记」连续记账；再次打开时沿用上次的类型与分类
- 支出 / 收入 / 互转 / 借贷 四种账目类型，借贷为「资金账户 ↔ 借贷账户」双账户记账，支持还款流水与批量收回
- 报销 / 退款、手续费 / 优惠：`实际金额 = 金额 − 报销退款 − 优惠 + 手续费`，余额与统计都按实计算，账单详情里展示完整算式
- 应收 / 应付备忘：不计入余额，收款 / 付款时才生成真实账单，支持分批结算、合并结算与销账
- 标签：一笔账可挂多个标签，标签可在设置里管理，也可在记账页快捷新建
- 备注记忆：记过的备注会按前缀联想；备注、对方、金额等输入统一走独立输入窗口，不被输入法遮挡
- 底部属性胶囊：日期 / 时间 / 退款 / 手续费 / 优惠 / 统计口径 / 标签
- 振动反馈与按键音可分别开关（按键音走闹钟音频流，手机静音 / 勿扰模式下照常响）

### 账户与账本
- 账户分组类型可自定义（按账本独立），支持隐藏账户、备注、不计入净资产
- 账户顺序拖动排序（独立页面），余额可直接调整并可选「是否生成调整账单」
- 删除账户可选「保留账单」或「连同账单一起删除」
- 多账本：账单、账户、分类、周期规则、预算、标签完全按账本隔离；账本删除走回收站（30 天可还原）

### 统计与报表
- 总览：日 / 月 / 年 / 自定义区间收支对比、分类环形图（大类 / 小类 / 账户三种维度，支持收入 / 支出切换）、趋势折线图、借贷汇总
- 报表页：按时间范围统计、分类表格、本月累计收支曲线（带预算线）、环比上月、一级分类近 12 个月趋势，可导出竖长图片
- 月度报告卡：一张图总结本月收支，可保存 PNG 或分享
- 收支日历：月历上直接看每天的收支
- 自定义预算：自定义事项 + 自定义时间段 + 分类 / 账户 / 关键词条件，支持支出 / 收入两种口径
- 预算预警线（默认 80%，可改 90% 或关闭）：到线先提醒一次，超支再提醒一次

### 智能辅助（纯本地）
- 记账建议：按「备注关键词 + 习惯时段 + 金额档」从你的历史里推荐分类与账户，只提示不自动改
- 一句话记账（Beta）：输入「午饭 25 支付宝 · 昨天」自动拆成类型 / 分类 / 金额 / 账户 / 时间
- 异常账单检测：疑似重复扣款、金额偏高的支出会在首页提示，可逐条查看或忽略

### 数据安全
- 回收站：删除的账单 / 账户 / 账本保留 30 天，可还原 / 彻底删除
- 完整备份与恢复：zip 全库备份（含全部设置、账本、账单、周期规则、回收站），恢复前自动快照、导入前预览、失败整体回滚
- 每月自动备份：打开 App 时检查，距上次满 30 天静默备份一次，存到 `Documents/Lumo/自动备份`，最多保留 3 份并提醒清理
- CSV / Excel 导入导出：UTF-8 / GBK 编码与多种分隔符自动识别，导入前可预览列映射、逐行勾选
- 首启引导 + 一键生成示例账本（约 80 笔演示数据，可整本删除）
- 数据库升级一律走 Room Migration，从不清库；启动时自动做完整性自检

### 桌面与外观
- 4 个桌面小组件：今日收支、快速记一笔、剩余预算、模板记账
- 桌面快捷方式：长按图标直达「记一笔」或「本月明细」
- 深色 / 浅色 / 跟随系统三档，三套主题色；悬浮胶囊底栏带真实毛玻璃（Android 12+，旧系统自动降级），可一键「减弱视觉效果」
- 小票模式（把本月账单渲染成小票图片）、账单可附小票照片（存本机私有目录）

## 五、构建方法

### 环境要求
- JDK 17
- Android SDK（compileSdk 34、build-tools 34）
- Gradle 8.7 —— **仓库自带 wrapper**（`gradlew`），首次运行会自动下载 Gradle，无需手动安装

### 准备 `local.properties`
在**项目根目录**（与 `settings.gradle.kts` 同级）创建 `local.properties`，指向你的 Android SDK：

```properties
sdk.dir=/path/to/Android/Sdk
```

Windows 示例：

```properties
sdk.dir=D\:\\Android\\Sdk
```

### 构建

```bash
# Windows
gradlew.bat :app:assembleDebug        # Debug 包
gradlew.bat :app:assembleRelease      # Release 包（R8 压缩）
gradlew.bat :app:testDebugUnitTest    # 跑单元测试（168 个）

# macOS / Linux
./gradlew :app:assembleRelease
```

产物位置：

```
app/build/outputs/apk/release/app-release.apk
app/build/outputs/apk/debug/app-debug.apk
```

### 关于签名
仓库**不包含签名文件与密码**（`app/bookkeeping.jks`、`app/keystore.properties` 均在 `.gitignore` 中忽略）。
`app/build.gradle.kts` 会自动判断：

- 本地存在 `app/bookkeeping.jks` **且** 配有 `app/keystore.properties`（或设置了 `KEYSTORE_PASSWORD` 等环境变量）→ 用它签 Release；
- 任一缺失（例如你刚 clone 下来）→ 自动退回 **debug 签名**，`assembleRelease` 依然能直接跑通，方便你先跑起来看看。

`keystore.properties` 格式（本地自建，勿提交）：

```properties
storeFile=bookkeeping.jks
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```
